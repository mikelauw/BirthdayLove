    Aktifkan Fitur AI

    Fitur AI membutuhkan Anthropic API Key.
    Key kamu tersimpan hanya di perangkat ini dan tidak dikirim ke mana pun selain Anthropic.

    Cara mendapatkan API Key gratis: 1. Buka console.anthropic.com
    2. Daftar / Login dengan email
    3. Klik API Keys → Create Key
    4. Salin key (dimulai dengan sk-ant-...) & paste di bawah

    Key disimpan di localStorage browser kamu.
    Tidak ada server — semua berjalan langsung di perangkatmu.
